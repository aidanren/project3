Episode Guessing Game

This interactive, responsive web application challenges users to test their knowledge of Breaking Bad and Friends by matching randomly selected episode titles to their correct season and episode numbers within a custom-branded interface.

Project Description:

Designed and developed an interactive, responsive web application that challenges users to guess random episodes of Breaking Bad and Friends. Built using HTML, CSS, and JavaScript, the project showcases a complete UX/UI workflow, spanning from initial research and wireframing to usability testing. It features intuitive grid layouts, show-specific branding, and dynamic visual feedback to create an engaging and user-friendly digital experience across all devices.
